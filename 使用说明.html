SimIme 拟人化中文输入器 · 使用说明

一句话：把一段中文粘进去，它退到后台；你切到目标窗口按 F9，它就锁定你的插入点、像真人一样一个字一个字地打出来 —— 带随机快慢、思考停顿、偶尔打错再退格改回，最后静默待机，只留托盘图标。

1. 这是什么 / 怎么启动

  • 免安装：整个程序就在一个文件夹里，双击 SimIme.exe 即可。
  • 托盘常驻、任务栏不出现：启动后只在右下角通知区域出现一个 SimIme 图标；鼠标悬浮能看到当前状态。
  • 单实例：重复双击 exe 不会开出第二个，只会唤醒已在运行的那个（换新版本前要先从托盘退出旧实例）。

2. 第一次使用：三步

  1. 双击 SimIme.exe → 托盘出现 SimIme 图标（任务栏不会出现按钮）。
  2. 双击托盘图标（或右键 →「唤醒 / 显示主界面」）→ 打开主界面，把要打的中文粘进去，点「确认开始」。
  3. 主界面自动隐藏。切到你真正要打字的窗口（记事本 / 浏览器 / 微信…），把光标放到要开始的位置，按一下 F9。

→ 程序开始逐个词地打；打完最后一个字后自动静默（悬浮条消失、热键注销、进程仍在托盘待命）。

3. 热键表

热键作用说明
F9开始 / 二次确认切到目标窗口、光标就位后按它才开始；避免误触
F8点击定位按 F8 后有一个倒计时，用鼠标点一下目标输入框，程序按点击位置重新定位插入点
F12停止随时中止。若 F12 被别的软件占用，程序会自动兜底到 F10/F11/F7/F6（顺序见 config.json 的 Hotkeys.StopKeyCandidates）
托盘右键唤醒 / 进入静默 / 退出静默后热键已注销，只能从托盘唤醒
小提示：日志里若出现 F12 被占用，停止键自动切到 F10，说明兜底生效了 —— 此时你按 F10 就是停止。

4. 悬浮条怎么看

打字时屏幕左下角（跟随插入点）会有一个像真输入法一样的悬浮条：

  • 上行：正在打的拼音，逐字母长出来（蓝色加粗带下划线）—— 这是模拟输入法，不会把拼音打进文档里。
  • 下行：带序号的候选词，当前选中的那个浅蓝高亮。
  • 打错再改的时候：先看到拼音被敲出来 → 候选高亮在那个错词上 → 错字落屏 → 退格删掉 → 重新敲正确拼音 → 正确字落屏（全程看得见）。
  • 悬浮条永不抢焦点，不会打断你在目标窗口里的输入。

5. 停止、暂停与唤醒

  • 中途停止：按停止键（默认 F12，被占用则自动兜底）。
  • 目标窗口失焦时：默认暂停（Behavior.FocusLostPolicy: Pause）。
  • 打完自动静默：悬浮条收起、热键全部注销（这时 F9/F8 不再被占用）、进程继续留在托盘。
  • 再次使用：双击托盘图标 → 窗口回来 → 再粘一段 → 重复第 2 节。

6. 想改手感？改 config.json

用记事本打开 dist/config.json，改完重启程序生效。

打字速度与节奏（Engine.Rhythm）

想要的效果参数现在是
每个字更快 / 更慢CharDelayMinMs / CharDelayMaxMs90~260ms
快慢变化更大 / 更均匀SpeedVariancePct35%
偶尔连打一段（更像真人）BurstChancePct12%
思考停顿更短 / 更长ThinkPauseMinMs / ThinkPauseMaxMs500~2500ms
多久思考一次ThinkEveryMinChars / ThinkEveryMaxChars每 8~20 字
休息（长停）时长RestPauseMinMs / RestPauseMaxMs3000~8000ms
多久休息一次RestEveryMinSentences / RestEveryMaxSentences每 2~5 句
按下开始后多久真正动手StartupDelayMs1500ms
标点前后额外停顿PunctuationExtraMinMs / PunctuationExtraMaxMs80~400ms

悬浮条（Inject）

想要的效果参数现在是
拼音字母打字速度PinyinLetterMs110ms/字母
候选高亮停留时长SelectHighlightMs220ms
显示几个候选CandidateMax6
标点之前的停顿BeforePunctPauseMs200ms
短拼音最少看得见多久MinComposeVisibleMs260ms

重打后停多久再选词AfterRetypePauseMs400ms

7. 它会学习你的用词（用户词表）

  • 你打的词块会被记下来，出现次数够了（默认 3 次，Engine.UserWordMinCount）就成为一个用户词组，之后切分和候选会优先用它。
  • 数据存在 dist/habits.dat；双击 看用户词表.cmd（或 words.cmd）可以查看当前学了哪些词。
  • 想从零开始：退出程序，删掉 habits.dat / habits.version / habits_merges.tsv 三个文件再启动即可。

8. 更新词典（可选，联网）

  • 主界面里有「联网更新词典」按钮（也可双击 更新词典.cmd / update-dict.cmd）：从镜像下载一份补充词表（约 4.6 万条），写进 dist/dict_extra.tsv，不需要重新编译。
  • 词表优先级：用户词组 > 外部词表（dict_extra.tsv）> 内置词典（全部按最长匹配）。
  • 下载地址在 Behavior.DictMirror（默认阿里云镜像）；失败不影响使用（会写日志说明原因）。

9. 出问题时怎么排（按顺序试）

  1. 按 F9 没反应：先确认目标窗口是前台、光标在输入框里；再确认程序没在静默状态（双击托盘唤醒）。
  2. F9/F8 被别的软件占了：改 config.json 的 Hotkeys.StartKey / LocateKey（键码：F8=119、F9=120、F10=121、F11=122、F12=123），重启程序。
  3. 打了字但没进目标窗口：多半是权限问题（见第 10 节）。双击 权限自检.cmd 看结论。
  4. 记事本里显示成方框（□ □ □）（新版记事本）：这是记事本自己的字体回退问题，不是内容错了 —— 按 Ctrl+A、Ctrl+C 粘到别处，或直接看窗口标题栏（标题栏里是正常中文）；也可把记事本字体换成「微软雅黑」。
  5. 想验证到底注入对了没有：双击 自检落屏.cmd（verify-ime.cmd），它会往指定窗口打一段测试文本并回读比对。
  6. 想看它每一步在干什么：dist/error.log 是运行日志（重建版本时自动归档保留最近 3 份，不会丢）。
  7. 悬浮条外观不对劲：双击 看悬浮条外观.cmd（bartest.cmd），它按真实运行时的构造依次演示悬浮条的所有正常状态。

10. 权限说明（很重要）

  • 程序默认普通权限运行。Windows 的 UIPI 机制不允许普通权限程序往管理员权限的窗口里注入（会被系统静默丢弃，程序也不知道）。
  • 要给管理员窗口打字：右键 SimIme-Admin.exe → 以管理员身份运行。
  • 不确定当前会不会被拦：双击 权限自检.cmd，它会打印自身完整性 / 目标完整性 / 结论。

11. 已知限制（如实列出）

  1. 新版记事本（带格式工具栏）在某些字体下把中文画成方框 —— 记事本的字形回退问题，内容是对的（看标题栏或粘出来即可验证）。
  2. F12 被别的软件占用时，停止键会自动兜底到 F10（顺序可在 config 改）。
  3. 标点直接上屏，不经悬浮条的组串与候选 —— 这与真输入法一致（日志里有一行「标点直接上屏（不经组串）」）。
  4. 普通权限对管理员窗口注入会被 UIPI 静默丢弃（见第 10 节）。
  5. 重复输入类错字（同一个词打两遍）默认关闭（Typo.RepeatWordPct = 0）。
  6. 换新版本前请先从托盘退出旧实例（单实例保护：新双击只会唤醒旧的）。
